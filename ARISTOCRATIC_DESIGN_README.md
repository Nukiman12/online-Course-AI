# 👑 EduAI - Аристократический дизайн

## 🎨 Что нового?

Ваш проект EduAI теперь имеет **премиальный аристократический черно-белый дизайн** с видео фоном на главной странице!

### ✨ Основные изменения:

1. **🖤 Черно-белая цветовая схема**
   - Монохромная палитра (черный, белый, серый)
   - Высокий контраст для максимальной читаемости
   - Элегантный и профессиональный вид

2. **📹 Видео фон на главной странице**
   - Динамичный фоновый видео
   - Автоматическое воспроизведение в цикле
   - Черно-белый фильтр для стилизации

3. **✏️ Новая типографика**
   - Playfair Display для заголовков (serif, аристократичный)
   - Inter для основного текста (sans-serif, современный)
   - Uppercase стиль для акцентов

4. **🎯 Жесткие тени (Hard Shadows)**
   - Геометрические тени вместо мягких
   - Эффект при наведении на элементы
   - Премиальный вид карточек

5. **🎭 Анимации и переходы**
   - Плавные появления элементов
   - Эффекты при наведении
   - Floating анимации

## 🚀 Запуск проекта

### 1. Backend (если еще не запущен)

```bash
cd backend
python -m venv venv

# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate

pip install -r requirements.txt
python init_db.py
python main.py
```

Backend будет доступен на: `http://localhost:8000`

### 2. Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend будет доступен на: `http://localhost:5173`

## 📹 Настройка видео на главной странице

### Быстрый старт (текущая настройка)

Видео уже настроено! По умолчанию используется внешнее видео с Mixkit.

### Использование своего видео

1. **Создайте папку для видео:**
   ```bash
   mkdir frontend/public/videos
   ```

2. **Скопируйте ваше видео:**
   ```bash
   # Поместите видео в:
   frontend/public/videos/hero-background.mp4
   ```

3. **Обновите путь в коде:**
   
   Откройте `frontend/src/pages/Home.tsx` (строка 134):
   ```typescript
   <source src="/videos/hero-background.mp4" type="video/mp4" />
   ```

### Рекомендации для видео:
- 📐 Разрешение: 1920x1080 или 1280x720
- 📦 Размер: До 15 МБ
- ⏱️ Длительность: 10-30 секунд (зацикливается)
- 🎬 Формат: MP4 (H.264)
- 🎨 Тема: Минималистичная, элегантная

### Бесплатные источники видео:
- [Mixkit](https://mixkit.co/free-stock-video/)
- [Pexels](https://www.pexels.com/videos/)
- [Pixabay](https://pixabay.com/videos/)

**Подробная инструкция:** См. `frontend/VIDEO_SETUP.md`

## 🎨 Кастомизация дизайна

### Изменение цветов

Откройте `frontend/src/index.css` и измените переменные:

```css
:root {
  --primary: #000000;          /* Основной черный */
  --text-primary: #000000;     /* Цвет текста */
  --bg-primary: #ffffff;       /* Цвет фона */
  --border-color: #e0e0e0;     /* Цвет границ */
}
```

### Изменение шрифтов

В `frontend/src/index.css` (строка 1):

```css
@import url('https://fonts.googleapis.com/css2?family=Playfair+Display:wght@400;500;600;700;800;900&family=Inter:wght@300;400;500;600;700;800;900&display=swap');
```

### Изменение эффекта видео

В `frontend/src/index.css` (строки 636-648):

```css
.video-background video {
  filter: grayscale(100%) brightness(0.4);
  /* Измените на: */
  /* grayscale(80%) brightness(0.5) - менее черно-белый */
  /* grayscale(100%) brightness(0.3) - темнее */
}
```

**Полное руководство:** См. `frontend/DESIGN_GUIDE.md`

## 🐛 Возможные проблемы

### Видео не загружается?
1. Проверьте консоль браузера (F12)
2. Убедитесь, что путь к видео правильный
3. Проверьте формат (должен быть MP4)
4. Попробуйте другое видео или внешнюю ссылку

### Шрифты не загружаются?
1. Проверьте интернет-соединение
2. Очистите кеш браузера
3. Google Fonts должны быть доступны

### Стили не применяются?
1. Перезапустите dev-сервер: `npm run dev`
2. Очистите кеш: `Ctrl + Shift + R`
3. Проверьте консоль на ошибки
