# Frontend - EduAI

## Структура проекта

```
frontend/
├── src/
│   ├── api/
│   │   ├── axios.ts        # Настройка Axios и interceptors
│   │   └── services.ts     # API сервисы для всех эндпоинтов
│   ├── components/
│   │   └── Layout.tsx      # Главный layout с навигацией
│   ├── pages/
│   │   ├── Login.tsx       # Страница входа
│   │   ├── Register.tsx    # Страница регистрации
│   │   ├── Home.tsx        # Главная страница
│   │   ├── Courses.tsx     # Список всех курсов
│   │   ├── CourseDetail.tsx # Детальная страница курса
│   │   ├── MyCourses.tsx   # Мои курсы
│   │   ├── AIChat.tsx      # Чат с AI помощником
│   │   ├── Dashboard.tsx   # Панель студента
│   │   └── TeacherDashboard.tsx # Панель преподавателя
│   ├── store/
│   │   └── authStore.ts    # Zustand store для аутентификации
│   ├── App.tsx             # Главный компонент с роутингом
│   ├── main.tsx            # Entry point
│   └── index.css           # Глобальные стили
├── index.html
├── package.json
├── tsconfig.json
└── vite.config.ts
```

## Компоненты

### Страницы:
- **Login/Register** - Аутентификация пользователей
- **Home** - Главная страница с информацией о платформе
- **Courses** - Каталог всех курсов с фильтрацией
- **CourseDetail** - Детальная информация о курсе и уроках
- **MyCourses** - Курсы, на которые записан пользователь
- **AIChat** - Интерактивный чат с AI помощником
- **Dashboard** - Персональная панель студента
- **TeacherDashboard** - Панель управления для преподавателей

### Компоненты:
- **Layout** - Общий layout с навигацией и футером

## State Management

Используется **Zustand** для управления состоянием:
- **authStore** - Хранение пользователя и токена аутентификации

## Стилизация

- Используются inline стили для максимальной гибкости
- CSS классы для переиспользуемых элементов
- Градиенты и анимации для современного вида
- Полностью адаптивный дизайн

## Запуск

```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для продакшена
npm run build
```

Приложение запустится на http://localhost:5173
