## 🤖 AI Функции

### 1. Чат-помощник
- Отвечает на вопросы по курсам
- Объясняет сложные концепции
- Предоставляет дополнительную информацию

### 2. Умные подсказки
- Направляет мышление студента
- Задает наводящие вопросы
- НЕ дает прямых ответов

### 3. Генерация конспектов
- Автоматически создает краткие конспекты
- Структурирует ключевые моменты
- Выделяет важные термины

### 4. Поиск материалов
- Находит релевантные ресурсы
- Рекомендует книги и курсы
- Предлагает практические проекты

### 5. Проверка заданий
- Автоматически проверяет работы студентов
- Выставляет оценки по критериям
- Дает детальную обратную связь

### 6. Генерация материалов
- Создает практические задания
- Генерирует тесты
- Создает вопросы для самопроверки

### 7. Умное расписание
- Создает оптимальное расписание
- Учитывает предпочтения студента
- Следует педагогическим принципам

## 🚀 Как запустить

### Быстрый старт (3 команды):
```bash
# 1. Backend
cd backend && python -m venv venv && venv\Scripts\activate && pip install -r requirements.txt && python init_db.py && python main.py

# 2. Frontend (новый терминал)
cd frontend && npm install && npm run dev

# 3. Открыть браузер
# http://localhost:5173
```

### Автоматический запуск (1 команда):
```bash
# Windows
start.bat

# Mac/Linux
bash start.sh
```
