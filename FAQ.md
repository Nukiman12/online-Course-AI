# ❓ Часто задаваемые вопросы (FAQ)

## 🚀 Установка и запуск

### Q: Как быстро запустить проект?
**A:** Используйте скрипты автозапуска:
- **Windows:** Запустите `start.bat`
- **Mac/Linux:** Запустите `bash start.sh`

### Q: Какие требования для запуска?
**A:** 
- Python 3.8 или выше
- Node.js 16 или выше
- OpenAI API ключ
- 500 MB свободного места

### Q: Что делать, если backend не запускается?
**A:**
```bash
cd backend
python -m venv venv
# Windows: venv\Scripts\activate
# Mac/Linux: source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

### Q: Что делать, если frontend не запускается?
**A:**
```bash
cd frontend
rm -rf node_modules package-lock.json
npm install
npm run dev
```

## 🔑 OpenAI API

### Q: Где получить OpenAI API ключ?
**A:** 
1. Перейдите на https://platform.openai.com/api-keys
2. Зарегистрируйтесь или войдите
3. Создайте новый API ключ
4. Скопируйте ключ в `backend/.env`

### Q: Сколько стоит использование OpenAI API?
**A:** 
- GPT-4 стоит около $0.03 за 1K токенов (вход) и $0.06 за 1K токенов (выход)
- Для тестирования достаточно $5-10 кредитов
- Можно получить бесплатные кредиты при регистрации

### Q: AI функции не работают, что делать?
**A:**
1. Проверьте API ключ в `backend/.env`
2. Убедитесь, что ключ начинается с `sk-`
3. Проверьте баланс на https://platform.openai.com/usage
4. Проверьте интернет соединение

### Q: Можно ли использовать другую AI модель?
**A:** Да! В файле `backend/ai_service.py` можно изменить:
```python
model="gpt-4"  # измените на "gpt-3.5-turbo" для экономии
```

## 👥 Пользователи и аутентификация

### Q: Какие тестовые аккаунты доступны?
**A:** После запуска `init_db.py`:
- **Студент:** student / password
- **Преподаватель:** teacher / password
- **Администратор:** admin / password

### Q: Как создать нового пользователя?
**A:** 
1. Откройте http://localhost:5173/register
2. Заполните форму регистрации
3. Выберите роль (студент/преподаватель)

### Q: В чем разница между ролями?
**A:**
- **Студент:** может записываться на курсы, использовать AI помощника
- **Преподаватель:** может создавать курсы + все возможности студента
- **Администратор:** полный доступ ко всем функциям

### Q: Можно ли изменить роль пользователя?
**A:** Да, через базу данных или API. В будущем можно добавить админ панель.

## 📚 Курсы и уроки

### Q: Как создать курс?
**A:**
1. Войдите как преподаватель
2. Перейдите в "Панель преподавателя"
3. Нажмите "Создать курс"
4. Заполните информацию о курсе

### Q: Как добавить уроки к курсу?
**A:**
1. Выберите курс в панели преподавателя
2. Нажмите "Добавить урок"
3. Заполните содержание урока
4. Сохраните

### Q: Можно ли добавить видео к урокам?
**A:** Да, укажите URL видео при создании урока (YouTube, Vimeo и т.д.)

### Q: Как студенты записываются на курсы?
**A:**
1. Просмотрите каталог курсов
2. Откройте интересующий курс
3. Нажмите "Записаться на курс"

## 🤖 AI функции

### Q: Какие AI функции доступны?
**A:**
- Чат-помощник (ответы на вопросы)
- Умные подсказки (без прямых ответов)
- Генерация конспектов курсов
- Поиск учебных материалов
- Автоматическая проверка заданий
- Генерация практических заданий
- Умное расписание обучения

### Q: Как использовать AI помощника?
**A:**
1. Перейдите в раздел "AI Помощник"
2. Выберите тип запроса
3. Задайте вопрос
4. Получите ответ от AI

### Q: Как сгенерировать конспект курса?
**A:**
1. Откройте страницу курса
2. Нажмите "Сгенерировать конспект"
3. Подождите несколько секунд
4. Конспект будет сохранен в материалах курса

### Q: AI дает неточные ответы, что делать?
**A:**
- Формулируйте вопросы более конкретно
- Указывайте контекст курса
- Используйте разные типы запросов
- При необходимости можно настроить промпты в `ai_service.py`

## 📊 База данных

### Q: Где хранятся данные?
**A:** В файле `backend/eduai.db` (SQLite база данных)

### Q: Как очистить базу данных?
**A:**
```bash
cd backend
rm eduai.db
python init_db.py
```

### Q: Можно ли использовать PostgreSQL?
**A:** Да! Измените `DATABASE_URL` в `backend/.env`:
```env
DATABASE_URL=postgresql://user:password@localhost/eduai
```

### Q: Как сделать бэкап базы данных?
**A:**
```bash
cd backend
cp eduai.db eduai_backup.db
```

## 🔧 Технические вопросы

### Q: На каких портах работает приложение?
**A:**
- Backend: http://localhost:8000
- Frontend: http://localhost:5173
- API Docs: http://localhost:8000/docs

### Q: Как изменить порты?
**A:**
- Backend: В `backend/main.py` измените `uvicorn.run(app, port=8000)`
- Frontend: В `frontend/vite.config.ts` измените `server: { port: 5173 }`

### Q: Как добавить HTTPS?
**A:** 
1. Получите SSL сертификат
2. Настройте reverse proxy (nginx/apache)
3. Или используйте uvicorn с SSL параметрами

### Q: Можно ли деплоить на сервер?
**A:** Да! Рекомендации:
- Backend: Heroku, Railway, DigitalOcean, AWS
- Frontend: Vercel, Netlify, Cloudflare Pages
- Database: PostgreSQL на Heroku или Supabase

## 🐛 Решение проблем

### Q: Ошибка "Module not found"
**A:**
```bash
# Backend
pip install -r requirements.txt

# Frontend
npm install
```

### Q: Ошибка CORS
**A:** Проверьте настройки CORS в `backend/main.py`:
```python
allow_origins=["http://localhost:5173"]
```

### Q: База данных заблокирована
**A:**
```bash
# Закройте все процессы Python
# Удалите .db файл и создайте заново
cd backend
rm eduai.db
python init_db.py
```

### Q: JWT токен истек
**A:** Измените время жизни токена в `backend/.env`:
```env
ACCESS_TOKEN_EXPIRE_MINUTES=10080
```
