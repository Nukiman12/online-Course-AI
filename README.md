# 🎓 EduAI - Платформа онлайн-образования с AI помощником

EduAI - это современная платформа для онлайн-обучения с интегрированным искусственным интеллектом, который помогает студентам и преподавателям в процессе обучения.

## ✨ Основные возможности

### Для студентов:
- 📚 **Каталог курсов** - Широкий выбор курсов по различным направлениям
- 🤖 **AI Помощник** - Интеллектуальный помощник, который отвечает на вопросы и помогает с учебными материалами
- 💡 **Умные подсказки** - AI дает подсказки, не раскрывая прямых ответов
- 📝 **Автоматические конспекты** - AI генерирует краткие конспекты по курсам
- 🔍 **Поиск материалов** - AI помогает находить релевантные учебные материалы
- 📅 **Умное расписание** - Автоматическое создание оптимального расписания обучения
- ✅ **Отслеживание прогресса** - Следите за своими достижениями

### Для преподавателей:
- ➕ **Создание курсов** - Легкое создание и управление курсами
- 📖 **Управление уроками** - Добавление, редактирование и удаление уроков
- 🤖 **AI ассистент** - Автоматическая проверка работ студентов с помощью AI
- 📊 **Генерация материалов** - AI помогает создавать учебные материалы и тесты
- 👥 **Управление студентами** - Просмотр и управление записями на курсы

## 🛠️ Технологии

### Backend:
- **FastAPI** - Современный, быстрый веб-фреймворк для Python
- **SQLAlchemy** - ORM для работы с базой данных
- **SQLite** - База данных (легко заменяется на PostgreSQL)
- **OpenAI GPT-4** - Интеграция с реальным AI для всех функций
- **JWT** - Аутентификация и авторизация
- **Pydantic** - Валидация данных

### Frontend:
- **React 18** - Современная библиотека для построения UI
- **TypeScript** - Типизированный JavaScript
- **Vite** - Быстрый сборщик модулей
- **Zustand** - Управление состоянием
- **React Router** - Маршрутизация
- **Axios** - HTTP клиент
- **Lucide React** - Иконки

## 📋 Требования

- **Python 3.8+**
- **Node.js 16+**
- **npm или yarn**
- **OpenAI API ключ** (получите на https://platform.openai.com/api-keys)

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
cd module
```

### 2. Настройка Backend

```bash
# Переход в директорию backend
cd backend

# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Настройка переменных окружения
# Откройте файл .env и добавьте ваш OpenAI API ключ
# OPENAI_API_KEY=sk-your-api-key-here
```

### 3. Настройка Frontend

```bash
# Открыть новый терминал и перейти в директорию frontend
cd frontend

# Установка зависимостей
npm install
```

### 4. Запуск приложения

**Terminal 1 - Backend:**
```bash
cd backend
# Активируйте виртуальное окружение если не активировано
python main.py
```
Backend запустится на `http://localhost:8000`

**Terminal 2 - Frontend:**
```bash
cd frontend
npm run dev
```
Frontend запустится на `http://localhost:5173`

### 5. Открытие приложения

Откройте браузер и перейдите по адресу: **http://localhost:5173**

## 🔑 Первый запуск

### Регистрация пользователей

1. Откройте http://localhost:5173/register
2. Зарегистрируйтесь как:
   - **Студент** - для прохождения курсов
   - **Преподаватель** - для создания курсов

### Создание тестовых данных

После регистрации как преподаватель:
1. Перейдите в "Панель преподавателя"
2. Создайте несколько курсов
3. Добавьте уроки к курсам

Как студент:
1. Просмотрите доступные курсы
2. Запишитесь на интересующие курсы
3. Используйте AI помощника для обучения

## 🤖 Настройка OpenAI API

1. Получите API ключ на https://platform.openai.com/api-keys
2. Откройте файл `backend/.env`
3. Замените значение `OPENAI_API_KEY`:
```env
OPENAI_API_KEY=sk-ваш-реальный-ключ
```

⚠️ **Важно:** Без настроенного API ключа OpenAI функции AI не будут работать!

## 📚 API Документация

После запуска backend, документация API доступна по адресу:
- **Swagger UI:** http://localhost:8000/docs
- **ReDoc:** http://localhost:8000/redoc

## 🎯 Основные API эндпоинты

### Аутентификация:
- `POST /api/auth/register` - Регистрация
- `POST /api/auth/login` - Вход
- `GET /api/auth/me` - Текущий пользователь

### Курсы:
- `GET /api/courses` - Список всех курсов
- `GET /api/courses/{id}` - Детали курса
- `POST /api/courses` - Создать курс (преподаватель)
- `PUT /api/courses/{id}` - Обновить курс
- `DELETE /api/courses/{id}` - Удалить курс

### Уроки:
- `GET /api/courses/{id}/lessons` - Уроки курса
- `POST /api/lessons` - Создать урок
- `PUT /api/lessons/{id}` - Обновить урок
- `DELETE /api/lessons/{id}` - Удалить урок

### AI Функции:
- `POST /api/ai/chat` - Чат с AI помощником
- `GET /api/ai/chat-history` - История чата
- `POST /api/ai/generate-summary` - Генерация конспекта
- `POST /api/ai/generate-practice` - Генерация практических заданий
- `POST /api/ai/generate-schedule` - Генерация расписания
- `GET /api/ai/resources` - Рекомендации ресурсов

### Записи на курсы:
- `POST /api/enrollments` - Записаться на курс
- `GET /api/my-enrollments` - Мои курсы

### Задания:
- `POST /api/assignments` - Создать задание
- `POST /api/assignments/{id}/submit` - Отправить решение
- `GET /api/my-assignments` - Мои задания

### Расписание:
- `POST /api/schedules` - Создать событие
- `GET /api/my-schedule` - Мое расписание

## 🐛 Решение проблем

### Backend не запускается:
```bash
# Проверьте установку зависимостей
pip install -r requirements.txt

# Проверьте Python версию
python --version  # должна быть 3.8+
```

### Frontend не запускается:
```bash
# Очистите кэш и переустановите зависимости
rm -rf node_modules package-lock.json
npm install
```

### AI функции не работают:
- Проверьте, что указан правильный OpenAI API ключ в `backend/.env`
- Убедитесь, что у вас есть кредиты на аккаунте OpenAI
- Проверьте интернет соединение

### Ошибка базы данных:
```bash
# Удалите базу данных и создайте заново
cd backend
rm eduai.db
python main.py
```
